# Slide step sheet

For each candidate slide:
- ID, teaching idea, concept kind, why motion is useful.
- Initial state and reading targets.
- Each click: fragment index, focal change, destination state, dependent labels and values, API used.
- Reverse/jump behavior and expected final static state.
- Ambient motion (if any), location and meaning.
- Layout constraints, source references, scientific checks.
- Verification: screenshots of every settled state plus representative intermediate transitions; no overflow or competing motion; rapid clicks and backward/forward restore same values.
